# gdb-remote-probe-server-go

一个**完全本地、可复现**的远程调试探针服务：用进程内的镜像加载器、受保护
内存的小型虚拟机和串行调试协议，替代真实调试器、探针硬件与外部服务。
支持并发调试会话管理、`$…#cc` 帧校验/确认/重传、能力协商、独占会话、
内存/寄存器/断点一致性，以及异常报文与非法操作的可区分错误处理。

## 架构

| 包 | 职责 |
| --- | --- |
| `pkg/image` | 本地镜像格式：内存布局、权限、符号、CRC 校验；裁剪镜像仍可加载 |
| `pkg/target` | 受保护内存 VM：寄存器、单步/继续/中断、4 个硬件断点、故障分类 |
| `pkg/protocol` | `$…#cc` 帧、`+/-` 确认、超时/NAK 重传、重复抑制、可损伤管道 |
| `pkg/session` | 能力协商、独占会话、命令分发、运行中拒绝、空闲超时、断连收敛 |
| `pkg/clock` | 真实时钟与确定性 `FakeClock`（重传/超时测试无睡眠驱动） |
| `cmd/probe` | 端到端脚本化演示 |

## 快速开始

```bash
go test ./... -race -count=10      # 全部测试，竞态检测，确定性重复
go test ./pkg/session/ -race -v    # 打印报文、会话状态与拒绝原因
go run ./cmd/probe                 # 端到端演示：加载/协商/断点/中断/分离
```
